Эта сборка Orion

Что добавлено поверх базовой библиотеки.

Не универсальный рейтинг библиотек, а конкретные отличия этого форка для проектов, которым нужны эти функции.

01

Шесть языков интерфейса

Английский, русский, украинский, польский, испанский и немецкий; можно зарегистрировать собственный словарь.

02

Темы с настройкой палитры

Пять встроенных тем, регистрация своей цветовой схемы и изменение цвета без пересоздания окна.

03

Редактор Luau внутри UI

Нумерация строк, поиск, замена, режим только для чтения и управление фокусом. Редактор не исполняет введённый код.

04

Опциональные модули и утилиты

Жизненный цикл модулей, обнаружение AFK по выбору разработчика, сигналы и функции debounce/throttle.

05

Меньше обязательных сетевых зависимостей

Базовые иконки сопоставлены локально; для создания основного интерфейса библиотеке не нужно скачивать удалённый каталог иконок.

06

Адаптация к сенсорному вводу

Размеры и обработка управления учитывают мобильные устройства; предусмотрены режим производительности и очистка подключений.

Другие UI-библиотеки могут быть лучше для иных задач. Orion имеет смысл выбирать, когда нужен именно этот набор возможностей и совместимый API.

Начало работы

Создайте первое окно.

В Roblox Studio поместите библиотеку в ModuleScript и подключите её из LocalScript.

StarterPlayerScripts / LocalScript●
local ReplicatedStorage = game:GetService("ReplicatedStorage")
    local OrionLib = require(ReplicatedStorage:WaitForChild("Orion"))

local Window = OrionLib:MakeWindow({
  Name = "Мой проект",
  Theme = "Glass",
  Language = "ru",
})

local Tools = Window:MakeTab({Name = "Tools"})
Tools:AddButton({Name = "Run", Callback = function()
  print("Ready")
end})

Справочник API

Методы и примеры.

Откройте раздел, чтобы посмотреть сигнатуру и пример использования.

01ТемыВстроенные палитры, свои темы и цвета

Переключайте тему окна или зарегистрируйте собственную палитру.

OrionLib:RegisterTheme("Ocean", {
  Main = Color3.fromRGB(18, 24, 32),
  Second = Color3.fromRGB(27, 38, 51),
})
Window:Theme("Ocean")
Window:SetThemeColor("Ocean", "Main", Color3.fromRGB(20, 30, 40))
02Редактор LuauТекст, поиск, замена и управление фокусом

Виджет редактирует текст внутри интерфейса и не исполняет его.

local Editor = Tab:AddCodeEditor({
  Text = "print('Привет')",
  ReadOnly = false,
})
Editor:Focus()
print(Editor:Get())
Editor:ReplaceAll("Привет", "Готово")
Editor:Blur()
03МодулиНеобязательные функции с Init и Destroy

Модуль должен реализовать хотя бы один метод жизненного цикла.

Window:RegisterModule("Tools", {
  Init = function(Context)
    print("Модуль включён")
  end,
  Destroy = function(Context)
    print("Модуль выключен")
  end,
})
Window:EnableModule("Tools")
04Состояние AFKОбнаружение бездействия и возврата

Отслеживание выключено по умолчанию. Минимальный таймаут составляет 10 секунд.

Window:ConfigureAFK({
  Enabled = true,
  Timeout = 300,
  Callback = function(IsAFK, Reason)
    print(IsAFK, Reason)
  end,
})
print(Window:IsAFK())
05ИконкиЛокальный каталог и свои идентификаторы

Зарегистрируйте короткое имя для Roblox asset ID и используйте его во вкладке.

OrionLib:RegisterIcon("settings", 1234567890)

local Tab = Window:MakeTab({
  Name = "Настройки",
  Icon = "settings",
})
06УтилитыЗащищённый вызов, задержка и сигналы

Общие функции доступны через OrionLib.Utils и Window.Utils.

local Utils = Window.Utils
local Delayed = Utils.Debounce(function(Value)
  print(Value)
end, 0.2)
Delayed("готово")

local Signal = Utils.CreateSignal()
local Connection = Signal:Connect(print)
Signal:Fire("событие")
Connection:Disconnect()
07Экран загрузкиНастройка заставки при создании окна

Заставка включена по умолчанию на ПК и выключена в режиме производительности. Полоса показывает анимацию ожидания, а не процент реальной загрузки.

local Window = OrionLib:MakeWindow({
  Name = "Мой проект",
  IntroEnabled = true,
  IntroText = "Мой проект",
  IntroSubtitle = "Подготавливаем интерфейс",
  IntroDuration = 2,
  IntroIcon = "rbxassetid://1234567890",
})

По этому запросу ничего не найдено.

Совместимость

Основная среда проверки — Roblox Studio.

Сторонние инжекторы не поддерживаются. Они могут менять окружение и доступность Roblox API, что способно вызвать ошибки, нестабильность или закрытие клиента. Библиотека не контролирует инжектор и не может гарантировать стабильный запуск через него; причину вылета нужно устанавливать по полному логу и воспроизводимому сценарию.
